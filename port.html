PROJECT 01

UPI Guard

Real-Time Transaction Fraud Analyzer

Project Overview

UPI Guard is a project designed to analyse transaction information and identify potentially suspicious transactions using machine learning.

Project Objective

The objective is to help detect unusual transaction patterns and provide risk information that can support fraud monitoring.

Key Features

  • Transaction risk analysis
  • Suspicious transaction alerts
  • Transaction history review
  • Charts and reports
  • User login and admin dashboard

Technologies Used

MongoDB, Express.js, React.js, Node.js, Python and Flask.

My Learning

This project helps me learn full-stack development, API integration and the use of machine learning in transaction analysis.
